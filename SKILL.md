# Guarded Canvas changes

Use only the registered `canvas` MCP tools. Never use memories, shell commands, `curl`, direct
Canvas API calls, or a hand-built MCP client for live Canvas work. If the tools are unavailable,
stop and ask the person to check the `canvas` server in `/mcp`.

- For an ordinary Canvas write, read [references/writes.md](references/writes.md) only.
- For rubric creation or grading, read [references/rubrics.md](references/rubrics.md) only.

Every change is previewed before it is applied. Show the exact preview and obtain the person's
approval before applying it. Never retry a result marked `WRITE STATUS UNCERTAIN` or
`do_not_retry`; read back the target and report what Canvas holds.
